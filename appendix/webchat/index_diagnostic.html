재시도는 Loader 초기화를 다시 시도합니다. 이미 생성된 채팅 위젯의 인증 세션을 초기화하지는 않습니다. 위젯이 표시된 뒤 인증 오류가 발생했다면 페이지 새로고침 또는 재로그인을 권장합니다.

브라우저 진단 이벤트

Authentication Error 대응 순서

  1. watsonx Orchestrate에서 Channels → Embedded agent의 대상 환경(Draft 또는 Live) Embed 스크립트를 다시 복사해 설정과 대조합니다. Live 사용 시 Agent 배포 상태를 확인합니다.
  2. 관리자에게 Settings → Embed Security 구성을 확인받습니다. 보안이 활성화된 경우 공식 절차에 따라 서버 측 개인키 관리 및 서명된 JWT 인증을 구현해야 합니다. HTML에 API Key 또는 개인키를 넣지 마세요.
  3. Chrome 개발자 도구 → Network → Fetch/XHR에서 실패한 요청의 HTTP 상태(401/403/404/5xx)와 응답 유형을 확인합니다. 토큰·쿠키·개인정보는 공유하지 마세요.
  4. 사이트를 file://가 아닌 http://localhost:8000으로 접속하세요. 시크릿 창에서도 동일한지 확인합니다.
이 페이지는 Loader 로딩 및 브라우저 오류에 대한 보조 진단만 제공합니다. 브라우저 보안 정책 때문에 타사 위젯 내부의 인증 오류, 실제 API 상태 및 서버 응답을 항상 자동 수집할 수는 없습니다. Loader 로드 성공 ≠ 인증 성공입니다.
